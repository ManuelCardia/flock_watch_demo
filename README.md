# Flock Watch — Non-Invasive Sheep Health Monitoring 🐑

**TU/e — 5ARF0: Ethics of AI (Phase 2 | Group ANWE I)**  
*Authors: Mariano Gustavo Pareja Ramirez, Konstantinos Parmaksidis, Anna Maniou, Manuel Cardia*

This is an AI-assisted decision-support system designed for early, non-invasive detection of sheep health anomalies using stationary raceway sensors (thermal, gait, acoustic) and 3D facial recognition. It prioritizes animal welfare (Five Domains Model), human agency, and compliance with EU Regulation 2016/429 without requiring individual wearable tags.
